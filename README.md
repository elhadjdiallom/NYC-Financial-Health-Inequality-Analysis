# NYC-Financial-Health-Inequality-Analysis
Tableau dashboard analyzing financial health disparities across NYC neighborhoods using NYC Open Data.
NYC Financial Health Inequality Analysis
#  Overview

This project analyzes financial health disparities across New York City neighborhoods using the NYC Department of Consumer and Worker Protection's Neighborhood Financial Health Index dataset.

The interactive Tableau dashboard highlights geographic inequality, borough comparisons, vulnerable neighborhoods, and key financial stability indicators.

## ** Key Questions **

Where is financial vulnerability concentrated across NYC?

How do boroughs compare overall?

Which neighborhoods have the lowest financial health scores?

What indicators drive vulnerability?

# Key Insights

The Bronx consistently shows lower financial health scores compared to other boroughs.

Manhattan and Brooklyn demonstrate stronger average financial performance, though variation exists within boroughs.

Vulnerability is driven by multiple indicators including employment, savings, and income stability.
